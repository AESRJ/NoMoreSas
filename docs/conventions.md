# Convenciones

Documentación y commits en español; rutas sin espacios ni acentos. IDs persistentes para requisitos, tareas y decisiones. Markdown UTF-8 y JSON válido. No elegir todavía convenciones de aplicación sin acordar el stack.

Primera entrega Git: `chore: montaje de arnés y estructura de agentes`. Cuerpo: alcance del montaje, decisiones y comandos ejecutados. Usar la identidad de la cuenta verificada de GitHub cuando no haya configuración local; el correo noreply verificado por login e ID es válido. Nunca cambiar la identidad global del equipo.

No añadir trailers automáticos de agentes; la bitácora sí identifica la asistencia de Codex y Claude. No incluir secretos ni resultados inventados. Cada sesión actualiza estado y añade su resumen al historial. Para corregir una entrada antigua, añadir una nueva corrección.
