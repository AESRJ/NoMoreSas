# ADR 0007: partir del servicio conocido

Fecha: 2026-11-22. Aceptada dentro del feedback explícito del usuario.

El catálogo público pasa de listas separadas y una comparación global a círculos de servicios con alternativas desplegables y comparativa en la misma página. Crear proyectos también parte de buscar el servicio conocido. Las fichas, relaciones y proyectos permanecen; no borrar datos para cambiar navegación.

005 define el alcance, textos y pruebas. El árbol debe ser DOM accesible, con teclado y movimiento reducido. Las comparaciones usan fuentes y muestran lo desconocido. Se mantiene la imagen y la paleta aprobadas. Se simplifica la ayuda de contraseña sin cambiar los límites ni el hashing.
